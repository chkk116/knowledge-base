# 知识库平台 v1.3.3

发布日期：2026-10-22

## 本次更新

### 界面与偏好
- **偏好设置**（新）：头像下拉 / 侧边栏「偏好设置」/ 顶栏齿轮三个入口都能进
  - 布局：侧边导航 / 顶部导航（窄屏自动回退侧边抽屉）
  - 侧边栏：显示开关、深色菜单、折叠后鼠标悬停临时展开
  - 内容宽度：流式 / 定宽；内容密度：标准 / 紧凑
  - 外观：跟随系统 / 浅色 / 深色主题，6 种强调色
  - 通用：登录后落地页（上次访问 / 首页）、一键恢复默认
  - 偏好保存在本机浏览器，改完即时生效

### 考试与练习
- **双模式答题**：考试模式（限时计分、交卷出成绩）与练习模式（答一题立即判分并显示答案解析，不计成绩）
- **模拟练习**：管理员在试卷上标记「设为模拟卷」后，全站统一使用该卷；学员在 Web 与 App 都可直接进入练习
- **组卷更灵活**：组卷时可自定义总分与及格分，总分按题数平均分配（余数给前面几题）
- **答题卡与错题本**：练习支持点题号自由跳题、对/错/主观/未答状态、本轮正确率与错题回顾；练习流水落库生成错题本，答对自动移出，也可手动标记「已掌握」
- **成绩回顾排版修复**：题干、选项、解析按富文本渲染；正确答案逐条列出，多选答案显示为「A、B」，不再挤成一段

### 安全与稳定
- 练习判分改为**会话校验 + 限流**：判分只接受本次练习内的题目，考试进行中无法通过练习接口查看答案
- 题干/选项/解析统一下发前做 HTML 消毒，避免存储型 XSS
- AI 出题校验：单选/判断必须恰好 1 个正确项、多选至少 2 个，不满足直接丢弃并提示
- OCR：复用 HTTP 客户端连接，4xx/5xx 返回明确原因（限流/鉴权/服务异常）
- 批量删除加事务；按分类组卷改为「草稿 → 装题 → 发布」，避免出现空卷中间态

### 开发与构建
- `npm run dev` / `build` 不再依赖 PATH（显式用 node 调用 vite），修复部分机器报「vite 不是内部或外部命令」
- 新增 `frontend/dev.cmd`、`frontend/build.cmd` 一键脚本：自动检测并安装依赖
- Vite 缓存目录改用系统临时目录，下载包换机器也能正常启动
- 首次 `npm run dev` 需等待依赖预构建（约 2-3 分钟），之后启动约 5 秒

## 升级说明

- 后端：替换 `kb-platform-0.0.1-SNAPSHOT.jar` 后重启（首次启动 JPA 自动补 `practice_enabled` 等新列）
- 前端：解压 `frontend-1.3.3.tar.gz`，把 `dist-v133` 内容部署到静态目录；部署后强制刷新（Ctrl+F5）
- App：本版本 `versionName=1.3.3 / versionCode=28`，需重新打包安装
